# Changelog

All notable changes are documented here. This project follows Semantic Versioning after `1.0`; alpha releases may refine tool contracts with release notes.

## 0.1.0 — 2026-09-24

- First public alpha.
- Local stdio MCP built on the stable MCP TypeScript SDK v2.
- Goal-tree creation with acyclic prerequisites and explicit canonical-node reuse.
- Deterministic forest overview, search, node context, diagnosis, and learning queue.
- Append-only notes and auditable verification records.
- Evidence-gated `verified` status for novel, unassisted, closed-book demonstrations.
- Workbench-compatible JSON envelope, atomic writes, cross-process locking, and snapshots.
- English and Chinese onboarding, product brief, architecture, security policy, and CI.
